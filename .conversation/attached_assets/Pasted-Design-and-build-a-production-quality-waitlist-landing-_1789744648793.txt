Design and build a production-quality waitlist landing page for a new cloud storage technology startup.

## Product concept

The product is a cross-platform cloud filesystem inspired by products such as SpaceFS, but designed from the ground up for both mobile and desktop.

The core concept:

Users can access a large amount of cloud storage from their phone or computer while keeping only the files they actually need locally. Files should feel accessible like normal local files, while the underlying data is stored securely in the cloud.

The product will eventually have:

* Android app
* iOS app
* Windows desktop client
* macOS desktop client
* Linux desktop client
* Web dashboard
* Virtual cloud drive
* On-demand file streaming
* Intelligent local caching
* Automatic synchronization
* Photo/video backup
* File sharing
* Offline files
* Large-file support
* Team/workspace storage

For now, DO NOT build the full application. Build only the public marketing website and waitlist signup experience.

---

# Primary objective

The entire website should drive one action:

**Join the waitlist**

The visitor should immediately understand:

1. What the product does
2. Why it is different from conventional cloud storage
3. Who it is for
4. What they can expect
5. How to join the early-access waitlist

The page should feel like a serious technology startup preparing for launch — not a generic SaaS template and not an AI-generated website.
